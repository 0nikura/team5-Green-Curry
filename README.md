# 落とし物マッチングアプリ

学内の落とし物を探している人と、窓口で返却を担当する事務職員を支援するWebアプリです。授業の一環として、チームでスクラム開発に取り組んでいます。

## プロダクトゴール

落とし物を登録できて複数のプラットフォームで学校関係者が落とし物を探せて返却までサポートできることを目指します。

## プロダクトバックログ（PB）

| 番号 | 項目 |
| --- | --- |
| PB① | 落とし物を登録できる |
| PB② | カテゴリで検索できる |
| PB③ | 返却が終わったら情報を削除できる |
| PB④ | 落とし物を画像で見ることができる |
| PB⑤ | 特徴で絞り込むことができる |
| PB⑥ | 受け取りに行く時間の目安を事務に伝えることができる |

## 使用予定の技術

HTML、CSS、JavaScriptを基本とし、必要に応じてチームで追加の技術を検討します。
